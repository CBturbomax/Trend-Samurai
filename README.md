# 키워드 트래커 (레딧 + 검색 관심도)

키워드를 넣으면 2019-01부터 오늘까지 월별로 모아 차트로 보여주는 개인용 대시보드.

- 전용 서브레딧의 하루 평균 댓글 수·글 수
- 다른 서브레딧에서 키워드가 언급된 글 수
- 구글·유튜브 검색 관심도

## 실행

```bash
./run.sh
```

브라우저에서 http://localhost:8000 을 연다. 처음 실행 때 `.venv` 를 만들고 패키지를 설치한다.
데이터는 `data/tracker.db` (SQLite) 한 파일에 저장된다. 서버를 껐다 켜도 수집은 이어서 진행된다.

## 클라우드 배포 (GitHub → Railway 등)

1. 이 저장소를 GitHub에 올린다.
2. Railway에서 New Project → Deploy from GitHub repo → 이 저장소 선택 (`Dockerfile` 로 자동 빌드).
3. 서비스에 Volume을 추가하고 경로를 `/data` 로 지정한다. 없으면 재배포 때마다 수집한 데이터가 사라진다.
4. Variables에 `KT_PASSWORD` 를 넣는다. 주소를 아는 사람이 키워드를 지우지 못하게 비밀번호를 건다(아이디는 아무거나).
5. Settings → Networking에서 공개 주소를 만든다.

GitHub만으로는 서버를 돌릴 수 없다(GitHub Pages는 고정 페이지만 가능). 그래서 코드는 GitHub, 실행은 Railway 같은 서비스가 맡는다.

## 구조

| 파일 | 역할 |
|---|---|
| `app/sources/arctic.py` | arctic-shift 호출 (교체 가능) |
| `app/sources/trends.py` | 구글 트렌드 호출. `KT_TRENDS_PROVIDER=serpapi` + `SERPAPI_KEY` 로 유료 대안 전환 (serpapi 쪽은 실제 호출 시험 못 함) |
| `app/worker.py` | 작업 큐(워커 1개, 순차), 재시도·기간 축소·보류, 매일 증분 업데이트 |
| `app/main.py` | API, CSV 내보내기 |
| `app/config.py` | 요청 간격·재시도 횟수 등 설정 |
| `static/index.html` | 화면 전체 (차트는 손코딩 SVG) |

## 수집 규칙

- 순서: 월별 총계 → 구글 트렌드 → 언급 검색(최신 달부터 거꾸로)
- 언급 검색은 동시에 1개, 성공 뒤 3초 간격. 422가 나면 2초 뒤 바로 재시도(실측상 오래 쉬면 오히려 더 실패함). 20번 연속 실패하면 15초→30초→…최대 10분 대기
- 같은 창이 25번 실패하면 기간을 반으로 줄이고, 8일 이하에서도 실패하면 '보류' 후 나중에 재시도
- 100건이 꽉 차면 창을 반으로 나눠 다시 셈
- 받은 (서브레딧, 단어, 기간) 결과는 DB에 저장하고 다시 요청하지 않음. 진행 중인 달만 매일 06:10에 갱신

## 지표 주의

- 하루 평균 = 월 합계 ÷ 날짜 수. 진행 중인 달은 오늘까지 일수로 나눔. **자체 계산, 공식 수치 아님**
- 언급 글 수는 '제목'에 단어가 든 글만 셈. 변형별로 따로 세어 더하므로 한 제목에 두 변형이 있으면 중복됨
- 구글 트렌드는 0~100 지수. 같은 요청(같은 지역·구글/유튜브)에 넣은 검색어끼리만 높이 비교 가능
- arctic-shift 월별 총계는 아카이브 집계라 실제와 조금 다를 수 있음

## 유튜브

- "유튜브" 탭에 YouTube Data API 키를 한 번 넣으면 켜진다(또는 환경변수 `YT_API_KEY`). 키는 Google Cloud Console에서 무료로 만든다.
- 보는 것: 월별 업로드 영상 수, 조회수 합, 댓글 수 합, 조회수 상위 영상·채널
- 과거 달의 조회수·댓글은 "그 달에 올라온 영상의 현재 누적값"이다. 유튜브가 과거 월별 조회수를 주지 않기 때문. 대신 매일 누적값을 기록해 앞으로의 실제 증가 추세를 쌓는다.
- 하루 한도 10,000 단위(검색 1회 100 단위). 한도를 다 쓰면 다음 날 자동으로 이어서 받는다.
- 제목·설명·태그에 키워드가 실제로 든 영상만 센다.

## 레딧 전체 검색에 대해

- arctic-shift는 서브레딧을 지정해야만 단어 검색이 된다. 그래서 "언급을 볼 서브레딧"을 여러 개 골라 합계를 본다.
- PullPush는 서브레딧 없이 레딧 전체 검색이 되지만, 자동 수집은 운영자가 막아 두었다(응답: "does not provide free scraping resources for agents", 유료 문의는 Discord). 코드는 `app/sources/pullpush.py` 에 있고 기본은 꺼져 있다. 유료 이용을 협의한 뒤 `KT_PULLPUSH=1` 로 켜면 "레딧 전체" 탭이 생긴다.

## 이용 범위 (중요)

- arctic-shift와 pytrends는 **비공식·무보증**이다. 언제든 막히거나 닫힐 수 있다.
- 이 도구는 **개인 리서치용**이다. 외부 배포나 상업적 이용은 레딧 이용 약관상 회색지대이므로 하지 말 것.
